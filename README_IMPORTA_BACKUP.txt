POWER GYM - CREA E IMPORTA BACKUP

Modifiche:
- Nel riquadro backup ora ci sono solo due pulsanti: Crea backup e Importa backup.
- Importa backup permette di caricare un file JSON esportato dal sito.
- L'import aggiorna clienti e schede con lo stesso ID.
- Dopo l'import viene creato un log nella collezione Firebase backups.
- Nessuna cancellazione automatica dei dati.

Nota: prima di importare, il sito mostra una conferma con il numero di clienti e schede trovati.
